功能

多标签工作区

浏览器式标签页承载终端、文件、网页与侧边聊天，可弹出为独立窗口。

插件市场

搜索安装 DSH 生态插件，带中文描述、分类与可安装性标注。

跨工具会话导入

把 Claude Code、Codex、pi 的历史会话压缩成简报，在 DSH 里接着干。

自动更新

国内 CDN 分发增量更新包，新版本自动下载，重启即完成。

安装

  1. 下载对应芯片的 .dmg，双击打开
  2. 把 Dsh GUI 拖进「应用程序」
  3. 首次打开时 macOS 会确认一次「来自互联网的 App」，点打开
  4. 进入 设置 → 模型，填入 DeepSeek（或任意 OpenAI 兼容）API Key

需要 macOS 11 及以上。机器上已有 ~/.dsh（用过 dsh CLI 或 dsh web）会直接复用， 会话与命令行侧完全同步。
