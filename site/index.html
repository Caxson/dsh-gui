把 Claude Code、Codex、pi 的历史会话压缩成简报，在 DSH 里接着干。

自动更新

国内 CDN 分发增量更新包，新版本自动下载，重启即完成。

安装

  1. 下载对应芯片的 .dmg，双击打开
  2. 把 Dsh GUI 拖进「应用程序」
  3. 首次打开时 macOS 会确认一次「来自互联网的 App」，点打开
  4. 进入 设置 → 模型，填入 DeepSeek（或任意 OpenAI 兼容）API Key

说明

  • 需要 macOS 11 及以上。Apple Silicon 与 Intel 各有独立安装包。
  • 机器上已有 ~/.dsh（用过 dsh CLI 或 dsh web）会直接复用， 会话与命令行侧完全同步。
  • 本站只提供下载，源码与发行版本托管在 GitHub，构建过程公开可查。
