跨 agent 会话导入

换个工具，
不用从头讲起

Dsh GUI 会自动扫描本机 Claude Code、Codex、pi 留下的历史会话， 挑一条，它就把整段对话压缩成接续简报，在原来的工作目录里开一个新会话继续干。

简报里还附着原始记录的路径——缺细节时它会自己回去翻原文，而不是问你重说一遍。

功能

多标签工作区

浏览器式标签页承载终端、文件、网页与侧边聊天，可弹出为独立窗口。

插件市场

搜索安装 DSH 生态插件，带中文描述、分类与可安装性标注。

跨 agent 会话导入

Claude Code、Codex、pi 的历史会话一键接续，工作目录与上下文都带过来。

自动更新

国内 CDN 分发增量更新包，新版本自动下载，重启即完成。
